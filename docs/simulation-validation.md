# 合成行情数据源首版验收记录

本记录对应 2026-10-24 的本机验证。首版目标是生成可复现的市场输入，未用策略收益率作为验收标准。

下列性能数字和三版本测试结果是首版基线快照，对应后文记录的源码摘要。后续 CLI 已迁移到 Click / rich-click，并新增 `just sim-*` 命令；该迁移会改变源码摘要，旧数据可继续离线读取和校验，恢复生成需匹配原版本或选择新目录。

## 性能实测

平台为 `macOS-14.4.1-x86_64-i386-64bit`。性能脚本使用 Python 3.12.11、QuantLib 1.44、NumPy 2.5.1、pandas 3.0.5、PyArrow 25.0.0、Pydantic 2.13.4、optopsy 2.3.0。每项实验只有一个数据生成进程；本机并非隔离的性能测试机器，以下为本次实际观测值，不作为跨机器时延承诺。

耗时包括数据生成、写盘和路径完成前的完整业务校验。RSS 为进程历史峰值，包含 Python、QuantLib 和数据依赖。落盘大小为脚本统计时的数据集大小，不包含随后写入的 `benchmark.json`。

| 实验 | 路径数 | 期权报价行数 | 耗时 | 峰值 RSS | 落盘大小 |
|---|---:|---:|---:|---:|---:|
| 全年固定市场、默认完整合约链 | 3 | 1,915,956 | 239.12 秒 | 268.89 MiB | 43.086 MiB |
| 一个月非零波动率、缩小合约链 | 3 | 14,756 | 101.04 秒 | 194.45 MiB | 0.959 MiB |
| 同月组合价格/IV/价差冲击 | 1 | 5,076 | 35.77 秒 | 187.89 MiB | 0.316 MiB |

全年实验包含 252 个交易日、两个标的，采用默认的 8 周/24 个月到期覆盖、$5 行权价步长、现价 50%—150% 的补充范围及 200 × 400 有限差分网格。每条路径有 638,652 行期权报价和 4,368 行结算，三条路径均完成了文件及跨表覆盖校验。

全年实验的实际波动率、漂移为零，两标的初始价格均为 100，IV 均为 25%。这是刻意固定的完整链生命周期/存储基准，能够复用完全相同输入的定价结果：三条路径共有 1,890,252 次精确缓存命中、26,124 次 PDE 求解。不得将其吞吐量解释为一般随机行情的生成速度。

随机实验采用 `baseline.json` 中的非零实际波动率和不同标的 IV，共执行 14,326 次 PDE 求解，缓存命中 520 次，命中率约 3.52%。组合冲击实验执行 5,110 次 PDE 求解且没有缓存命中。PDE 求解次数包含 Greeks 中心差分及网格加密的额外求解，因此可能超过未命中缓存的报价数量。

## 复现命令与产物

```bash
.venv/bin/python scripts/benchmark_simulation.py \
  --config examples/simulation/annual-flat.json \
  --output .tmp/simulations/annual-flat-final --paths 3
.venv/bin/python scripts/benchmark_simulation.py \
  --config examples/simulation/baseline.json \
  --output .tmp/simulations/stochastic-final --paths 3
.venv/bin/python scripts/benchmark_simulation.py \
  --config examples/simulation/combined.json \
  --output .tmp/simulations/combined-final --paths 1
```

每个目录内有 `manifest.json`、分片 Parquet 和 `benchmark.json`。这些是被 Git 忽略的本地产物；重新运行需使用新目录。现有数据可通过 `simulate-market validate --input …` 验证。

首版保留的模型边界包括零分红、固定横截面 IV、合成挂牌、日频时钟和占位成交量。没有生成真实日内 0DTE、提前指派或实物交割事件，也没有进行历史参数校准。
